# Archived design documents

Documents in this directory describe superseded UI iterations and are retained only for historical context.

The current frontend information architecture is:

- `/library` — library and reading entry point
- `/activity` — crawl queue, active jobs, and recent task history
- `/sources` — source profile management
- `/settings` — application and reader preferences

The former standalone Crawl and Tasks pages were removed in July 2026. Compatibility redirects from `/crawl` and `/tasks` remain intentionally in the router.

For current requirements, use:

- `docs/superpowers/specs/2026-07-19-mobile-first-reader-app-redesign.md`
- `docs/superpowers/plans/2026-07-19-mobile-first-reader-app-redesign.md`
