# Documentation

These guides describe the supported public workflows for Novel Tool.

- [Getting Started](GETTING_STARTED.md) - install dependencies, configure a local environment, and start the app.
- [Configuration](CONFIGURATION.md) - environment variables, local administration, LAN access, and storage.
- [Plugin Development](PLUGIN_DEVELOPMENT.md) - author, package, install, approve, and test source plugins.
- [Security](SECURITY.md) - safe deployment, secrets, package integrity, and vulnerability reporting.

For contribution workflow, see [CONTRIBUTING.md](../CONTRIBUTING.md). Release history is kept in [CHANGELOG.md](../CHANGELOG.md).
